# Tokenizer

Goal: produce exactly the ids `transformers` (5.x, `tokenizers` 0.23) produces
for `BAAI/bge-m3`, without `sentencepiece`, `tokenizers` or `transformers`.

## Pipeline (dumped from the runtime `tokenizers` object)

```
AddedVocabulary : split literal <s> </s> <pad> <unk> <mask> (<mask> has lstrip=True)
Precompiled     : nmt_nfkc charsmap, applied per grapheme cluster
WhitespaceSplit : drop Unicode White_Space characters (Rust char::is_whitespace)
Metaspace       : prefix each word with U+2581 (prepend_scheme=always)
Unigram         : Viterbi best segmentation, unk score = min score − 10, fuse_unk
ids             : <s>=0 <pad>=1 </s>=2 <unk>=3 <mask>=250001, else spm id + 1
```

## Precompiled charsmap (the part that differs from SentencePiece)

The blob is `u32 trie_size | Darts double-array trie | NUL-separated
replacement strings`. SentencePiece uses the longest prefix match over the whole
input. Hugging Face (`spm_precompiled` crate) instead:

1. splits the text into extended grapheme clusters,
2. if the cluster is shorter than 6 UTF-8 bytes, looks the whole cluster up and
   takes the **first (shortest)** prefix match, replacing the whole cluster,
3. otherwise looks up each character separately.

Consequences reproduced here: `ﾊﾟ` → `ハ` + `゚` (6 bytes, per char), `Ａ́` → `A`
(the combining mark is dropped with the cluster), `▁` → space.

## Grapheme clusters

`_grapheme.py` implements UAX #29 rules GB3–GB13 including GB9c (Indic
conjuncts) and GB11 (emoji ZWJ). Tables are generated by
`tools/gen_grapheme_tables.py` from `GraphemeBreakProperty.txt`,
`emoji-data.txt` and `DerivedCoreProperties.txt` (Unicode 16.0). All 1094
cases of the official `GraphemeBreakTest.txt` pass.

## Unigram encoder

`UnigramModel.encode` runs the optimized Viterbi from `unigram_model.cc` /
`model.rs`: for each start position, dictionary lookups for substrings up to the
longest piece (16 chars), strict `>` on ties (first found wins), an `<unk>` node
only when no single-character piece exists, consecutive `<unk>` fused.
Scores are float64 like the Rust implementation.

## Verification

- `tests/fixtures/tokenizer_cases.json`: 109 curated cases (multilingual, NFKC,
  emoji, controls, literal special tokens, long inputs), generated by
  `tools/make_tokenizer_fixtures.py` with `transformers` 5.16.1.
- 3000 random multilingual strings compared one-off against HF: 3000/3000 equal.
- Speed: ~3 ms per 2000 CJK characters, ~0.3 s to load the model.

Known divergence: `transformers` 4.x loaded the Hub `tokenizer.json`, whose
pipeline emits an extra `▁` token for trailing whitespace. We follow 5.x, which
matches SentencePiece.
