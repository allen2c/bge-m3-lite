# Calibration set

SmoothQuant (`quantization/recipe.md`) needs per-channel activation statistics. They
come from two bundled files, loaded together by
`quantize.load_calibration_texts()` (`--calibration FILE` replaces both):

| file | lines | content | licence |
|---|---|---|---|
| `bge_m3_lite/calibration.txt` | 212 | hand-written sentences in 30+ languages, code (Python/SQL/JSON), maths, emoji, Unicode edge cases, URLs, random-script fuzz | MIT (this repository) |
| `bge_m3_lite/calibration_miracl.txt` | 360 | 20 Wikipedia passages (20–400 characters) for each of the 18 MIRACL languages: ar bn de en es fa fi fr hi id ja ko ru sw te th yo zh | CC BY-SA (see below) |

## MIRACL sample: provenance

- Dataset `miracl/miracl-corpus` on the Hugging Face Hub, revision
  `d921ec7e349ce0d28daf30b2da9da5ee698bef0d` (2026-09-06), fetched
  anonymously through the datasets-server REST API
  (`/rows?dataset=miracl/miracl-corpus&config=<lang>&split=train&offset=0&length=100`).
- Recipe (deterministic): for every language take the first 100 rows, keep
  passages of 20–400 characters, take the first 20, collapse newlines to
  spaces, strip the `[lang]` marker.
- Licence: the dataset card says Apache-2.0, but the passages are Wikipedia
  text segmented by WikiExtractor, i.e. **CC BY-SA 3.0/4.0** content. The
  sample is therefore distributed under CC BY-SA with attribution to the
  Wikipedia contributors and to MIRACL (Zhang et al., 2023,
  <https://huggingface.co/datasets/miracl/miracl-corpus>). It is data only;
  the package code stays MIT.
- It adds six scripts/languages the hand-written file lacked (Bengali,
  Persian, Swahili, Telugu, Yoruba, Indonesian) and natural encyclopaedic
  prose; it contains no code, tables or long documents, which is why the
  hand-written file is kept.

Alternatives checked and rejected on 2026-09-06: FLORES-200/FLORES+ and
`bigcode/the-stack-smol` are gated (token required); Tatoeba is not served
by datasets-server; XNLI is 15 languages of short NLI pairs; FineWeb (ODC-By)
is English only.

## Evaluation is disjoint

Accuracy is measured on two sets that share nothing with calibration:

- `tests/fixtures/embeddings_ref.*`: 11 FlagEmbedding reference texts.
- `tests/fixtures/heldout_*`: 40 texts (12 languages, code, a Markdown table,
  JSON, ~600-token paragraphs, dates, emoji, degenerate inputs), reference
  outputs from the fp32 fused graph (bit-exact with FlagEmbedding),
  regenerated by `tools/make_heldout.py`, which refuses overlaps with the
  calibration files. `tools/eval_model.py` reports both sets.
